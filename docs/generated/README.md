# Generated Documentation

This directory holds **auto-generated outputs** from the system.

## What goes here

- Experiment result tables (CSV/JSON/Markdown)
- Auto-generated evaluation metrics summaries
- Generated figures and charts for the paper
- Corpus statistics summaries
- Model performance comparison tables

## What does NOT go here

- Hand-written design docs (→ `docs/design-docs/`)
- Execution plans (→ `docs/exec-plans/`)
- Reference material (→ `docs/references/`)

## Rule

Everything in this directory is **generated by scripts**, not hand-written. If it needs to be edited, edit the script that generates it, not the output.
