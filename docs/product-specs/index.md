# Product Specs Index

Use this folder for current user-facing behavior specs.

## Active Specs

- `new-user-onboarding.md`: the first-run experience for a new user
  submitting their first meeting transcript and getting back a
  hierarchical recap.

## Planned Specs (not yet drafted)

- `chapter-title-editing.md`: how users rename chapters from the UI
  (depends on `ui-001` + `api-001`).
- `highlights-checkoff.md`: how users mark action items as done from the
  UI (depends on `ui-001` + `api-001`).

## Rules

- Specs describe user-visible behavior and acceptance criteria, not
  implementation details. When in doubt, prefer prose over pseudocode.
- If implementation diverges from the spec, update one of them in the
  same session so the spec and the code never drift.
- Keep this index current so a fresh agent can discover product scope
  quickly.
