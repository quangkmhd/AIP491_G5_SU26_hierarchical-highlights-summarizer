# model-002 — AI Model Loader & File Repository (Design Spec)

**Date:** 2026-07-04
**Status:** Approved (pending written review)
**Area:** `repo`
**Related plan:** `docs/exec-plans/active/model-002-model-loader.md`

## Goal

Implement the Repository layer so the rest of the pipeline can load
HuggingFace checkpoints and read/write transcript/recap JSON files.

## Decisions (locked)

### D1. CoherenceNet encoder

- **Architecture** (verified by inspecting `vibert_checkpoints_vi/cpt_4000.pth`):
  - BERT-base (12 layers, 768 hidden, 12 heads) + pooler
  - `coherence_decoder`: `Linear(768, 768) -> ReLU -> Dropout(0.1) -> Linear(768, 2)`
  - `state_dict` keys: `bert.*` (199 keys) + `coherence_decoder.{0,3}.*` (4 keys) = 203 total
- **Base encoder** (for tokenizer + non-embedding weights):
  - `bert-base-multilingual-cased` (vocab 119547)
  - Checkpoint vocab is 38168 (a Vietnamese-subset checkpoint was
    pre-trained from a smaller vocab). Loading the multilingual BERT
    base triggers 7 `UNEXPECTED` keys (the MLM head), which are
    ignored with `strict=False`.
  - Embedding rows for tokens outside the Vietnamese subset are
    present but unused at inference time.
- **Justification for picking the multilingual base** (not PhoBERT
  or `bert-base-vietnamese`): the checkpoint is the project's existing
  artifact; we keep the contract that the project's paper-1 NSP
  weights are the single source of truth for coherence scoring.
  Swapping base encoders is deferred until a Vietnamese base with
  vocab 38168 is verified to improve downstream P_k.

### D2. Paper-2 LLMs collapsed to one backbone

- Paper-2 specifies 4 fine-tuned models (BART/deBERTa). Per user
  decision, the project uses \*\*one Vietnamese-capable instruct LLM
  - custom prompts\*\* instead of fine-tuning four separate heads.
- **Default backbone:** `Viet-Mistral/gemma-4-E2B-it-qat-GGUF`
- **Quantization:** 4-bit via `bitsandbytes` (`load_in_4bit=True,
bnb_4bit_compute_dtype=torch.float16, bnb_4bit_quant_type="nf4"`)
- **Rationale:**
  - `bitsandbytes 0.49.2` is already installed; no new native deps.
  - 4-bit 7B ~ 5-6 GB VRAM -> fits RTX 4060 8 GB alongside CoherenceNet
    (463 MB) and KV cache.
  - Vietnamese fluency > multilingual alternatives; Apache-2.0 base.
- **Prompts (4 templates, all Vietnamese):**
  - `HIERARCHIC_SEGMENT_PROMPT_VI` -- sentence-pair -> boundary probability
  - `HIERARCHIC_ABSTRACTIVE_PROMPT_VI` -- 8-utt chunk -> rolling summary
  - `HIERARCHIC_TITLE_PROMPT_VI` -- segment utterances -> chapter title
  - `HIGHLIGHTS_PROMPT_VI` -- 10-utt window -> KEY_POINT/ACTION_ITEM
- Prompts are **strings** keyed by `LLMTask` enum; they live in
  `src/repo/prompts_vi.py` so they can be tuned without touching
  loader code.

### D3. ModelLoader shape

- **Per-process singleton** (HF model load is 5-30s/model; one loader
  per process is the only sane default).
- **API:**
  ```python
  loader = ModelLoader.instance()           # returns the process singleton
  nsp = loader.load_coherence_net()        # returns ModelHandle[CoherenceNet]
  llm = loader.load_llm_backbone()         # returns ModelHandle[AutoModelForCausalLM]
  ```
- **Caching:** dict keyed by `ModelKind`; second access returns the
  same `ModelHandle` instance.
- **Device remap:** if checkpoint was saved on `cuda:0` and current
  process has no GPU, `map_location` transparently remaps to `cpu`.
- **Offline mode:** env var `MODEL_LOAD_LLM=0` (or `.env`) skips the
  LLM download; `load_llm_backbone()` returns a `MockLLMBackbone`
  wrapper that records calls and returns canned strings. This is
  required for offline CI and unit tests.

### D4. Layer rules

- `src/repo/` may import from `src/types/` and stdlib + third-party
  (`torch`, `transformers`, `pydantic`).
- `src/repo/` MUST NOT import from `src/config/`, `src/service/`,
  `src/runtime/`, `src/ui/`. README in `src/repo/` confirms.
- The plan's "smoke loader" runs `ast` check to assert no forbidden
  imports -- this is enforced mechanically, not by convention.

### D5. TranscriptRepo contract

- **Input:** `data/eval_vi/{dialseg_711,doc2dial,meeting_ami,
meeting_committee,meeting_icsi,tiage}.json`.
- **Schema per entry:** `{dial_id, utterances, segments, set,
utterances_vi, utterances_en}` (no speaker labels; we synthesize
  `speaker="S{i+1}"`).
- **Output:** `DialogueTranscript` with `utterances_vi` as the
  canonical text (language metadata `"vi"`).
- **MAX_UTTERANCES check:** enforced both at repo level (defensive)
  and at `DialogueTranscript` validator (canonical).

### D6. RecapRepo contract

- **Write:** `HierarchicalRecap.model_dump_json()` to a path; canonical
  wire-format (Pydantic field names).
- **Read:** parse JSON back into `HierarchicalRecap`; raise
  `RecapRepoError` (typed) on file not found, JSON parse error, or
  Pydantic validation error.
- **Round-trip invariant:** `recap == RecapRepo.read(RecapRepo.write(recap, p), p)`
  for any valid `HierarchicalRecap`.

## Out of Scope

- Inference logic (`svc-001..svc-004`).
- FastAPI endpoints (`api-001`).
- Real LLM inference (this plan only loads + caches; inference tests
  use `MockLLMBackbone`).
- Switching `bert-base-multilingual-cased` to a smaller Vietnamese
  base (deferred to a follow-up plan with eval-001 evidence).
