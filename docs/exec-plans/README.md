# Execution Plans

This directory tracks **active and completed execution plans, experiment logs, and technical debt**.

## What goes here

- Research experiment plans with timeline
- Implementation execution plans (what to build, in what order)
- Experiment run logs (parameters, results, observations)
- Technical debt tracking (known shortcuts that need fixing)
- Blocked items and their resolution plans

## What does NOT go here

- Permanent design decisions (→ `docs/design-docs/`)
- Auto-generated metrics tables (→ `docs/generated/`)
- Reference documentation (→ `docs/references/`)

## Rule

Every experiment run gets logged here. Every tech debt item gets tracked here. This is the project's working memory.
